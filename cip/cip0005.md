## Summary

Ship a **static**, downloadable Formula 1 practice→qualifying dataset for the
**2011** season through the usual pods +
[datasets_mirror](https://github.com/lawrennd/datasets_mirror) path:

```python
data = pods.datasets.f1_2011_practice_qualifying(grand_prix="GreatBritain")
```

This supports GPy / GPc tutorial notebooks that recreate historical
practice→qualifying prediction demos (FP3 → Q cutoffs) without any live timing
client, subscription, or commercial data service.

**Design pivot (2026-11-23):** an earlier draft used a live FastF1 wrapper.
That approach is abandoned: it advertised a path that now depends on a
commercial F1TV subscription for timing archives. This CIP uses only curated
2011 tables hosted on `datasets_mirror`.

## Motivation

1. **Tutorials need offline-friendly data.** Labs and CI should not require
   interactive login or paid broadcast subscriptions to load a GP demo.
2. **Historical demos already exist.** Curated 2011 weekend timing covers
   seventeen grands prix (FP1–FP3, Q) in a form suitable for those demos.
3. **Static CSVs on the mirror.** Publish derived numeric tables for research
   and teaching — not live APIs and not branded PDF dumps.

## Detailed Description

### Scope

| In scope | Out of scope |
|----------|--------------|
| Full per-lap 2011 FP1/FP2/FP3/Q tables (all recorded laps) | Live / modern-season timing APIs |
| Q1/Q2/Q3 segment labels on qualifying laps where recoverable | Weather / Météo France radar |
| pods loader that can derive fastest clean practice + Q bests | GPS traces |
| Host files on `datasets_mirror` | Branded PDF / image assets |
| Unit tests against fixtures (no network in default CI) | Race-lap full tables (may add later) |

### Public API

```python
def f1_2011_practice_qualifying(
    grand_prix="GreatBritain",
    practice="FP3",
    data_set="f1_2011_practice_qualifying",
    refresh_data=False,
):
    """Load 2011 practice fastest laps and qualifying times from datasets_mirror."""
```

**Parameters**

- `grand_prix` — name matching the timing folders, e.g. `GreatBritain`,
  `Canada`, `Hungary`, `Australia` (see pack manifest).
- `practice` — `FP1`, `FP2`, or `FP3` (default `FP3`).
- `refresh_data` — re-download from the mirror.

**Returns** (via `access.data_details_return`)

| Key | Content |
|-----|---------|
| `X` | Practice fastest clean lap (seconds), shape `(n, 1)` |
| `Y` | Qualifying times (seconds). Prefer three columns Q1/Q2/Q3 when available; otherwise one column for session best with `nan` for missing segments |
| `driver_number`, `abbreviation`, `team`, `team_index` | Side arrays for GP covariates |
| `info` / catalogue fields | Provenance, year 2011, grand prix, practice session |

Drivers without a valid practice lap are omitted (same spirit as the historical
demo pipeline).

### Mirror pack layout

Under `datasets_mirror`:

```text
f1_2011_practice_qualifying/
  README.md                 # provenance and licence notes
  manifest.json             # list of grands prix and files
  GreatBritain/
    FP1_laps.csv            # every lap: times, sectors, speeds, pit flag, TOD
    FP2_laps.csv
    FP3_laps.csv
    Q_laps.csv              # same + q_segment (Q1/Q2/Q3) when windows known
  Canada/
    ...
  ...
```

CSV (UTF-8) only at runtime. The mirror stores **all laps**; the pods demo API
may still return fastest-clean aggregates by filtering `pit_stop == 0` and
taking minima. Generation scripts are **not** shipped in the pods wheel
(`notebook/scripts/curate_f1_2011_practice_qualifying.py`).

Default demo race: **GreatBritain** (Silverstone 2011).

### Curation rules

1. Emit one CSV row per recorded lap (including pit and incomplete times).
2. Preserve sector times, sector speeds, time-of-day, and pit flags.
3. Label qualifying laps with Q1/Q2/Q3 when session windows are known or
   inferred from multi-minute gaps; document source in `manifest.json`.
4. Loader-side (not pack-side): for GP demos, exclude pit laps and take the
   minimum finite `lap_time_s` per driver / Q segment.

### Provenance and licensing text (catalogue)

`data_resources` citation/details should state approximately:

- Derived from 2011 Formula 1 weekend timing used in University of Sheffield
  research on qualifying cut-off prediction.
- Curated numeric summaries for research and teaching.
- Not an official FIA or Formula 1 product.

### Explicit non-goals

- Do **not** depend on, document, or recommend FastF1, F1TV, OpenF1, or other
  commercial / subscription live-timing products in pods docs for this dataset.
- Do **not** commit raw timing archives or GPS zips into the pods or notebook
  git histories.

## Implementation Plan

1. **Curate tables**
   - Offline script: extract **all** FP1/FP2/FP3/Q laps for each 2011 grand prix.
   - Write `README.md` + `manifest.json`.

2. **Publish to datasets_mirror**
   - Add `f1_2011_practice_qualifying/` on
     `https://github.com/lawrennd/datasets_mirror`.
   - Record file sizes for `data_resources`.

3. **pods loader**
   - `pods.datasets.f1_2011_practice_qualifying`.
   - `data_resources.json` / `.yml` entries with mirror URLs.
   - Download via existing `access.download_data` / `data_available`.

4. **Tests**
   - Fixture CSVs in `pods/testing/fixtures/` (tiny synthetic or truncated
     GreatBritain) for offline unit tests.
   - Skip from the auto dimension-download sweep if the default call hits the
     network; cover with an explicit test that uses fixtures / mocked
     `DATAPATH`.

5. **Docs**
   - README optional-datasets section (no commercial timing services).
   - Point GPy/GPc notebook work (downstream) at this loader.

## Backward Compatibility

Additive. No existing loaders change. The abandoned FastF1-based API name
`f1_practice_qualifying` will not ship.

## Testing Strategy
